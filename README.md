# VRchat时间轴纪念相册

面向 VRChat 旅人的 **本地优先时光相册**。整理、回看与记录在世界之间拍下的照片，按时间轴浏览，为照片关联世界资料，并通过独立管理台维护照片、世界资料、站点文案与数据备份。

桌面客户端额外提供 **EasyTier 虚拟组网 P2P 传图**、**AI 视觉模型回忆总结** 与 **局域网手机客户端**；网页版保持相同的相册界面与本地优先逻辑。

外观提供 7 套配色、4 种时间轴布局与 **9 种动态背景**（星轨、雨幕、亚克力、实验性银河黑洞、樱吹雪、极光、萤火、自定义图片、循环视频）。银河黑洞默认隐藏，需要在管理台开启「实验性背景」后才会出现在背景列表中。客户端还提供 **网络代理管理** 与 **VRChat 官方世界封面拉取**。

视觉方向是日式 ACG 的暮色旅行手帖：暮色紫、樱花粉、奶油白、星轨时间轴、玻璃质感与微光。示例照片均为本作原创插画。

> 版本：**v2 数据架构 · 客户端 1.1（手机测试版）**
> 客户端下载：[GitHub Releases](https://github.com/GhostQAQ-VRC/-/releases/latest)
> 源码仓库：[GhostQAQ-VRC/-](https://github.com/GhostQAQ-VRC/-)
> 公开相册：`#/`
> 管理台：`#/admin`
> 高级设置：`#/admin/advanced`（客户端）

## 快速开始

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 类型检查 + 生产构建
npm run preview  # 预览 dist
```

技术栈：React 19、TypeScript、Vite、自写 CSS、lucide-react、Cormorant Garamond / Manrope。

首次进入管理台需要设置一个**本地管理口令**（至少 6 位），用于阻止误入管理页面。该口令使用 PBKDF2（SHA-256）哈希后保存在当前浏览器，不是服务器级身份认证。

## 本地客户端（Electron）

同一套 `src/` UI 同时服务网页与桌面客户端。客户端额外提供：

- 自定义标题栏、窗口状态记忆、单实例、原生菜单与文件对话框；
- **独立存储库**：选择或新建一个文件夹，原图只读，不压缩、不设体积上限；
- 递归扫描照片，读取 VRChat 照片内嵌的 XMP / VRCX JSON / EXIF / 文件名，识别拍摄时间与 `wrld_…` World ID；
- **两步首启 + 缩略图缓存**：先在存储库内新建缩略图文件夹，再从 5 档规格中选择；随机抽一张图做压缩前后 A/B 对比，并显示实测体积与滚动卡顿提示。确认后立即全库生成，向导内显示真实进度条与完成提示。网格与列表只加载缩略图，点开单张照片才加载原图；
- **三档图片加载策略**：实时加载（视口附近）、预测加载（默认，按滚动方向预取约 10–20 张并按显存预算收缩）、预先加载（后台预取全部缩略图字节，不提前解码）；离开视野自动释放解码内存，降低 GPU/CPU 占用；
- **EasyTier 虚拟组网**：检测/手动选择/一键下载组件，网络名称、密钥、Peer 列表、虚拟 IP、启动/状态/日志；
- **P2P 传图**：接收端分享码、好友地址测试、原图流式发送、收到后自动入库并识别日期/World ID；
- **手机客户端（局域网）**：管理台「手机同步」开启后显示二维码；手机扫码进入 `/m` 手机版，实时读取桌面相册。相册卡片长按上滑可投送照片到手机；接收方式可选「实时查看」（电脑临时当服务器，不占手机空间）或「保存到手机」（下载原图）。手机与电脑需在同一 Wi-Fi，不经过互联网；
- **Android APK**：`mobile-android/apk/VRchat-Timeline-Album-Mobile-1.1.0.apk`。原生连接页支持扫码/手动地址，配对后加载手机版；保存原图通过原生桥写入 `下载/Hoshikuzu/`。APK 仍需电脑端开启手机同步；
- **AI 图像总结**：OpenAI 兼容 / Anthropic / Gemini / Ollama，一键拉取模型、主/备模型、视觉模型限制、批量生成回忆总结；
- **AI 方向检测**：按「角色自拍时头顶朝上；没有人物时按 16:9 风景照不旋转」的规则调用视觉模型，支持单张与 16:9 横图批量校正；
- **更新提示**：启动后经当前代理检查 GitHub Release，发现新版本时右下角提示下载；设置页可手动检查；
- **AI 识图 World ID**：读取 VRChat 拍立得画面中印出的 `wrld_…`，自动补全世界关联（批量或单张）；
- **VRChat 官方世界资料**：登录官方账号（支持 2FA）后批量拉取资料库中所有 World ID 的名称、作者、简介、人数与封面；封面压缩为 512px WebP 入库，离线可见；
- **网络代理管理**：跟随系统 / 不使用 / HTTP / SOCKS5 / PAC / 自定义规则，可设置绕过地址并测试连通性，作用于 VRChat 官方 API 与渲染层远程请求；
- **循环视频背景**：导入 MP4 / WebM / MOV，体积过大时自动去除音轨并高质量压缩，画面保持高清；
- 整库 ZIP 备份、元数据备份、网页 JSON 备份迁移；
- **云同步**：云盘同步（Google Drive / 123云盘 / 百度网盘客户端同步目录、WebDAV、Google Drive API、百度网盘 API）按拍摄日期自动建立日期文件夹并上传原图；网站同步把相册数据 POST 到自定义接口；
- 同步密钥使用系统加密保存在本机，不写入存储库或备份。

## 公开相册

- 按年 / 月分组的时间轴，发光星轨、月份牌、年份章节与自动显现动画。
- 左右交替的照片卡片：大图、拍摄时间、备注、世界名称与资料来源。
- 时间轴快速导航：年份胶囊 + 月份轨道自动高亮；超宽屏显示右侧年份轨。
- 搜索备注、世界名称、作者、日期；按世界 / 未关联 / 待识别筛选；最新 / 最早排序。
- 空相册、无结果、存储受限状态。
- 照片详情：大图、备注编辑、未保存保护、键盘翻页、删除、世界关联与识别。
- 照片收录：支持本地图片选择 / 拖拽，也支持粘贴 `http(s)` 图片直链；链接照片只保存 URL，由原站提供图片。
- 照片置顶：在时间轴卡片或详情中一键设顶，首页开头的精选卡片会立即换成这张照片；再次点击可取消，取消后回到最新收录。
- 世界关联支持：
  - 粘贴 VRChat 世界链接或 `wrld_…` ID，自动解析；
  - 从本地世界资料库直接选择；
  - 查询成功 / 失败 / 超时 / 取消状态；
  - 失败后重试、手动录入、仅保留 World ID；
  - 更换、解除、复制 ID、打开 VRChat 世界页（内置资料会隐藏虚假跳转）。
- 照片卡片会按原图比例自动区分 **横图 / 竖图 / 方图**：竖拍自拍不再被裁成横向，横拍合照保持宽幅，方图使用 1:1 画框；时间轴、画廊、密排与首页精选卡片均已适配。
- **照片方向校正**：部分手机竖拍或 VRChat 手机相机截图会把竖画面以 1920×1080 横向像素保存，且没有 EXIF 旋转标记，程序无法仅凭宽高判断。卡片悬浮操作和照片详情都提供「向左/向右旋转 90°」，旋转只改变相册显示、不改写原图，并会随相册保存。
- 公开站头部常驻「外观」入口，可直接切换配色、时间轴布局与动态背景。
- 动态背景：星轨、雨幕、磨砂亚克力、樱吹雪、极光、萤火、自定义图片与循环视频背景；实验性「银河黑洞」需在管理台开启后才显示。支持减少动态效果偏好。
- 移动端时间轴、详情面板、上传对话框均已适配。

## 主题与布局

公开相册提供 7 套配色与 4 种时间轴布局，其中 **晨光 / 晴日** 是两套亮色主题。**公开站头部的「外观」按钮可以直接切换**，管理台 → 站点设置 → 外观与布局提供同样的完整控制。选择后立即保存并生效，也会随完整备份一起导出。### 配色主题
| 名称 | 气质 |
| --- | --- |
| **暮色紫**（默认） | 深紫夜空、樱花粉、月白微光。当前原始样式完整保留。 |
| **晨光** | 奶油白、樱花与晨雾，干净温暖的浅色纸页。 |
| **晴日** | 天空蓝、薄云与晴光，明亮而清爽的浅色相册。 |
| **樱夜** | 酒红夜色与更浓的樱粉，像没有结束的花见。 |
| **月白** | 靛蓝、冰银与淡紫，安静而清冷。 |
| **琥珀黄昏** | 褐金、蜜桃与晚霞，旧唱片的暖色封面。 |
| **青雾** | 深林绿、薄荷与一点樱花，潮湿而安静。 |

主题通过 `html[data-theme]` 与 CSS 变量切换（`--atmo-*`、`--sakura`、卡片/弹窗/管理台表面等），不会改变照片本身。`html[data-tone]` 同步标记亮 / 暗色调，`light-theme.css` 为浅色主题修正高光文字、玻璃层次与控件对比度。

### 时间轴布局
- **星轨交错**（默认）：中央星轨，照片左右交替，原布局不变。
- **双列画廊**：双列瀑布式画廊，弱化时间轴线；单张月份居中展示。
- **左侧编年**：左侧时间轨 + 横向照片条目，适合快速浏览大量回忆。
- **密排相册**：三列照片墙，只保留核心信息，适合像翻相册一样快速浏览。

布局通过 `html[data-layout]` 切换；桌面和手机各有适配。当前默认组合为 **暮色紫 · 星轨交错**。

### 动态背景
外观面板提供 9 种全屏背景，与主题独立组合，选择后立即保存并写入 `html[data-background]`：

| 背景 | 效果 |
| --- | --- |
| **星轨**（默认） | 缓慢漂移的星尘与偶尔划过的流星。 |
| **雨幕** | Canvas 雨丝 + 玻璃水滴，雨滴拍打后沿屏幕滑落并留下水痕；亮色主题自动切换为浅色水雾。 |
| **亚克力** | 磨砂亚克力板、柔和流动光与玻璃分层，适合做展板式留白。 |
| **银河黑洞**（实验性） | WebGL 实时着色器：事件视界、光子环、倾斜吸积盘、多普勒增亮、引力透镜扭曲、闪烁星海与流星；黑洞缓慢左右漂移，附近星光与尘埃被吸入。默认隐藏，需在管理台开启「实验性背景」。 |
| **樱吹雪** | 贝塞尔花瓣随风旋转飘落。 |
| **极光** | 低饱和极光帘幕缓慢流动，后方星空闪烁。 |
| **萤火** | 夜色中呼吸、聚散的发光萤火。 |
| **自定义图片** | 上传 JPG / PNG / WebP / AVIF，压缩到 1920px 内保存为相册背景；可替换或移除。 |
| **视频背景** | 导入 MP4 / WebM / MOV 等常见视频并循环播放。体积过大时自动去除音轨、限制到 1920px 长边并高质量重编码；原文件较小且为网页格式时直接使用，不重新压缩。客户端存入库内 `.hoshikuzu/backgrounds/`，网页版存入 IndexedDB。 |

动态背景使用独立固定层（`z-index: -2`），不会拦截鼠标；支持 `prefers-reduced-motion`，系统要求减少动态效果时视频背景只显示封面帧。亮色主题选择深色特效时会提示对比度风险。

黑洞属于实验性特效：默认关闭。管理台 → 站点设置 → 背景特效下方勾选「实验性背景」后，「银河黑洞」才会出现在公开站外观面板与管理台背景列表中；关闭开关时若正在使用黑洞，会自动回退到星轨。

## 管理台

访问 `#/admin`，或点击公开站头部 / 页脚的「管理台」，输入本地管理口令。

### 概览
- 照片、世界资料、年份、本地数据体积统计。
- 按年份的回忆分布、世界资料使用排行。
- 最近操作、最近收录照片、存储占用与系统状态。
- 数据健康提示：待识别世界、未关联照片、起始内容与内置资料数量。

### 照片管理
- 搜索、按世界 / 来源筛选、四种排序、分页。
- 桌面表格 + 移动端卡片两种布局。
- 编辑拍摄时间、备注、图片替代文本；世界关联变更随「保存修改」一起写入。
- 单张删除、批量选择、批量删除、批量解除世界关联。
- 单张照片可直接设为首页置顶；表格与移动端卡片会显示置顶标记。
- 世界关联修改会在保存前作为草稿处理，并支持未保存关闭保护。

### 世界资料库
- 维护独立的本地世界资料库，不依赖照片存在。
- 新增、编辑、删除世界资料；支持名称、World ID、作者、人数、简介、封面、管理备注。
- 可从已有照片中选择封面。
- **从 VRChat 官方拉取封面**（客户端）：登录 VRChat 账号后，一次读取资料库中全部 World ID 的官方名称、作者、简介与封面；封面会压缩成 512px WebP 存入相册，之后离线也能显示。支持 TOTP / 邮箱两步验证，密码可用系统 safeStorage 加密记住。
- 世界资料修改会**同步到所有关联照片**；删除时保留照片并解除关联。
- 内置起始资料可编辑、删除或替换为你的真实世界资料。

### 站点设置
- **外观与布局**：7 套配色（含晨光 / 晴日亮色主题）、4 种时间轴布局与动态背景即时切换；支持上传自定义图片或循环视频背景；当前默认「暮色紫 · 星轨交错 · 星轨」。
- **实验性背景**：默认关闭；开启后显示「银河黑洞」，关闭时自动隐藏并回退到星轨。
- **网络代理**（客户端）：跟随系统 / 不使用 / HTTP / SOCKS5 / PAC / 自定义规则，可设置绕过地址并测试连通性；VRChat 官方资料、远程图片与世界查询共用该代理。
- 站点中文名、英文副标题、首页引言、时间轴引言、首页置顶照片。
- 世界查询代理地址配置与连接测试。
- 数据与备份：导出完整 JSON 备份；导入备份（替换 / 合并）；移除起始内容；清空照片；恢复起始相册。
- 本地存储占用与数据摘要。
- 管理口令修改、立即锁定。

### 操作记录
- 记录照片、世界、设置、数据导入 / 清空 / 恢复以及首页置顶变更等操作，最多 120 条。
- 按类型筛选，清空记录需二次确认。
- 操作记录不包含管理口令，也不随备份导出到其他账户。

## 高级设置（仅客户端）

管理台 → **高级设置**（`#/admin/advanced`），包含：

### EasyTier 虚拟组网
- 自动检测、手动选择 `easytier-core.exe`，或从官方 GitHub Releases 一键下载 Windows 组件（约 31MB，LGPL-3.0，下载后按官方 SHA-256 校验）。
- 填写网络名称、网络密钥、虚拟 IPv4、Peer/服务器列表、监听与 RPC 端口；支持自动启动、免 TUN、自定义参数、等价 TOML 复制。
- 状态面板显示本机虚拟 IP、直连/中继对端、延迟/丢包/NAT 与运行日志；`cost=1` 为直连，`>=2` 为 relay。
- **TUN 模式需要管理员权限**（创建虚拟网卡）。可点「以管理员身份重启」提权，或启用 **免 TUN**（可被访问、不能主动发起）。
- 公共节点可用性不保证，建议自建共享节点；首次监听需放行 Windows 防火墙。

### P2P 图片传输
- 接收端：生成分享码、开启监听端口（默认 7878），显示 EasyTier 虚拟 IP 与局域网 IP；可复制「地址 + 分享码」给好友。
- 发送端：填写好友虚拟 `IP:端口` 与分享码，测试连接后选择照片，原图流式发送。
- 接收端收到后自动复制到 `<存储库>/_inbox/transfer/<日期>/`，识别日期/World ID 并加入相册；按内容哈希去重。
- 分享码使用系统加密保存；请求使用 Bearer 令牌与速率限制，单张 4GB 安全上限。

### 手机客户端（局域网）
- 管理台 →「手机同步」→ 开启；桌面会在局域网监听 HTTP（默认 7880），并显示二维码。手机与电脑连同一个 Wi-Fi，用相机扫码即可打开手机版 `/m`，无需安装 App。
- **Android APK**：如果希望像 App 一样安装，使用 [mobile-android/apk/VRchat-Timeline-Album-Mobile-1.1.0.apk](mobile-android/apk/VRchat-Timeline-Album-Mobile-1.1.0.apk)。APK 有原生连接页（扫码/手动地址/剪贴板），配对后加载同一套手机版，并通过原生桥把原图保存到手机「下载/Hoshikuzu」；电脑端仍必须开启手机同步。详见 [mobile-android/README.md](mobile-android/README.md)。
- 二维码包含临时配对令牌；扫码后手机获得 HttpOnly 配对 Cookie（12 小时），刷新二维码会立即作废旧链接。
- 手机端按年月浏览桌面存储库，支持搜索、年份/世界筛选、全屏查看与左右滑动；缩略图实时读取，点开原图也由电脑临时提供，**不写入手机存储**。
- **投送**：电脑相册卡片长按 380ms 后向上滑 56px 松手，出现全屏投送层；也可点卡片手机按钮或照片详情「投送到手机」。手机需保持页面打开（SSE 在线）。
- **两种接收方式**（电脑/手机任一端切换，双向同步）：
  - **实时查看**：电脑当临时服务器，原图 `no-store` 实时读取，不占用手机空间。
  - **保存到手机**：手机端立即开始下载原图（文件名沿用库内文件），并在浮层保留「保存到手机」按钮；iOS 保存到「文件」，Android 保存到浏览器下载目录。
- 手机端长按照片向上滑也可以把当前照片保存到手机。桌面服务不经过互联网，关闭同步或退出客户端即断开。

### AI 图像总结
- 协议：**OpenAI 兼容**（OpenAI / LM Studio / vLLM / OneAPI）、**Anthropic Claude**、**Google Gemini**、**Ollama 本地**。
- 填写 Base URL、API Key，测试连接；**一键获取全部模型**，自动标记视觉模型。
- 选择主模型与备用模型；主模型失败自动尝试备用。只有支持图片输入的视觉模型可以生成总结，未识别的模型需手动确认。
- API Key 使用 Electron `safeStorage`（Windows DPAPI）加密，仅保存在本机，不随存储库迁移。
- 生成时把 1024px JPEG 预览与拍摄信息发送给所配置的 API；不会发送原图。支持单张重新生成与批量生成（可停止）。

### AI 识图 World ID
- VRChat 拍立得会把世界 ID 直接印在照片边框上。除读取 PNG/EXIF 元数据外，可用视觉模型直接识别画面中印出的 `wrld_…`。
- 识别时把图片放大到最长边 2048px 的 JPEG（保证小字可读），提示模型只提取 `wrld_0a1b2c3d-…` 格式；返回结果再做正则校验与解析。
- 照片详情、管理台照片编辑器提供「AI 识图 World ID」按钮；高级设置的批量面板会统计「待识别 World ID」并一键批量识别，主模型失败自动切换备用。
- 识别成功后会建立/复用世界资料库条目、关联照片，并标记 `worldIdSource: 'ai'`；公开站管理台显示「AI 识图」标签。不会覆盖已手动关联或已解析的世界。
- 画面模糊、反光或世界 ID 被裁切时可能识别失败或识别错误；重要关联请人工核对。图片同样会发送给所配置的第三方 API。

## 数据模型与迁移

数据保存在浏览器 `localStorage`：

| 键名 | 内容 |
| --- | --- |
| `hoshikuzu-album-v2` | 照片、世界资料库、站点设置、操作记录 |
| `hoshikuzu-album-v1` | 旧版数据（自动迁移后保留） |
| `hoshikuzu-appearance-v1` | 当前配色与布局的小型缓存，用于首屏无闪烁恢复；可从相册数据重建 |
| `hoshikuzu-admin-credential-v1` | 本地管理口令的 PBKDF2 盐与哈希 |
| `hoshikuzu-admin-session-v1`（sessionStorage） | 当前标签页的管理解锁状态，8 小时过期 |

- 首次加载 v2 时，如不存在 v2 而存在 v1，会自动迁移照片与内嵌世界资料，并建立世界资料库。
- 页面在 React 挂载前读取外观缓存，避免亮色主题刷新时先闪出暗色背景或错误布局。
- 照片的 `worldRef` 指向世界资料库记录；世界资料同时保留在照片快照中，便于离线展示。
- 用户收录的照片以 `isRemote` 区分：`false` 为压缩后内嵌的本地图片，`true` 为只保存 URL 的链接照片。
- 起始照片带 `isSample` 标记，可在管理台移除。
- 客户端照片额外使用 `mediaKind`、`libraryPath`、`previewPath`、`contentHash`、`metaSource`、`missing` 等字段；AI 总结保存在 `aiSummary`、`aiTags`、`aiModel`、`aiUpdatedAt`、`aiState`、`aiError`；AI 识图的 World ID 关联来源记录在 `worldIdSource`（`scan` / `ai` / `manual`）。
- 站点设置新增 `backgroundEffect`、`experimentalEffects`（实验性背景开关，默认 `false`），以及自定义背景的 `customBackgroundSrc` / `customBackgroundName`（压缩后的 data URL，随相册数据与备份保存）。
- 客户端密钥（AI API Key、传图分享码、EasyTier 网络密钥）不在相册数据中，使用 `safeStorage` 加密保存在本机配置目录。
- 备份文件格式：

```json
{
  "format": "hoshikuzu-album-backup",
  "version": 2,
  "exportedAt": "2026-11-24T…",
  "data": {
    "version": 2,
    "photos": [],
    "worlds": [],
    "settings": {},
    "activity": []
  }
}
```

导入时会进行结构校验与字段清洗；支持按 ID 合并或完整替换。管理口令不包含在备份中。

**本地存储有容量限制（通常约 5MB）。** 上传图片会压缩为最长边 1440px 的 JPEG data URL；大量照片需要后端对象存储。链接照片只保存 URL，不占用图片体积，但加载依赖原站可访问并允许外链。管理台会显示占用并在接近上限时提示导出备份。

## 世界查询

世界识别封装在 `src/services/worldService.ts`，组件不直接发请求。结果始终携带来源，不会把本地 / 内置资料伪装成实时 API 数据。

### 离线模式（默认）
- 从本地世界资料库按 World ID 查找。
- 可粘贴链接或 ID；也可在照片详情里直接从资料库选择。
- 未命中时提示手动录入、保留 ID，或前往管理台新增世界。
- 内置起始世界会标注「内置资料」。
- 完全不需要网络，也不涉及任何 VRChat 凭据。

### 联网代理模式
在管理台「站点设置 → 世界查询代理」填入 Base URL，或设置：

```bash
# .env.local
VITE_WORLD_API_BASE=https://your-app.example.com/api
```

管理台中的运行设置优先于环境变量；清空后回到本地资料库模式。修改后无需重新构建。

代理需实现：

```http
GET {VITE_WORLD_API_BASE}/worlds/{worldId}
Accept: application/json
```

成功返回 `200`：

```json
{
  "id": "wrld_xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
  "name": "世界名称",
  "authorName": "作者名",
  "thumbnailUrl": "https://…",
  "description": "世界简介",
  "capacity": 32
}
```

未知世界返回 `404`。前端兼容 `worldName`、`imageUrl`、`author.name` 等字段，并处理 9 秒超时、网络错误与异常响应。代理必须允许前端来源的 CORS 请求。

**为什么需要后端代理：** VRChat 社区 API 需要登录态 / 2FA，浏览器不应携带私密凭据直接访问；代理负责认证、限流、缓存和响应清洗。请勿在 `VITE_*` 环境变量、前端代码或管理台中保存 VRChat 密码、cookie 或 API key。请遵守 VRChat 服务条款，控制请求频率，并仅缓存必要字段。

> 桌面客户端是例外：它在主进程中使用独立的持久会话登录 VRChat 官方账号，密码可选 `safeStorage` 加密保存；浏览器端仍然只通过代理 Base URL 查询。

本地联调可用仓库自带的模拟代理：

```bash
npm run mock:world
# 另开终端
VITE_WORLD_API_BASE=http://127.0.0.1:5199 npm run dev -- --port 5175
```

Windows PowerShell：

```powershell
$env:VITE_WORLD_API_BASE="http://127.0.0.1:5199"; npm run dev -- --port 5175
```

### 架构要点
- `useAlbum` 是唯一数据源：照片、世界资料库、设置、操作记录、持久化与迁移都在这里。
- 公开站与管理台共享同一个 store；路由切换不复制数据。
- 世界资料库修改会集中同步所有引用照片；照片详情与管理员编辑器共用 `WorldPanel`。
- 配色、布局与动态背景由 `AlbumSettings.theme/layout/backgroundEffect` 持久化，通过根节点 data 属性、CSS 变量与 Canvas/WebGL 图层即时应用。
- 所有破坏性操作都有二次确认或未保存保护。
- 管理台使用 hash 路由，静态站点部署无需服务器 rewrite 规则。
- 桌面客户端通过 `DesktopLibraryProvider` / `DesktopServicesProvider` 接收存储库、P2P 与 AI 事件；主进程负责文件、密钥、网络与外部进程。

## 已知限制

- 网页：相册数据存 localStorage，容量约 5MB；客户端使用独立存储库，不受此限制。
- EasyTier 组件需下载或手动选择；TUN 模式需要管理员权限，免 TUN 不能主动发起连接；公共中继可用性不保证。
- P2P 传图只在双方都运行客户端、加入同一 EasyTier 网络且接收端开启时可用；分享码只应发给信任的好友。
- 手机客户端只在同一局域网、桌面客户端开启「手机同步」且防火墙放行端口时可用；使用 HTTP（非 HTTPS），部分浏览器的系统分享/剪贴板能力不可用，保存走下载。iOS 切后台会暂停页面导致 SSE 断开，回到前台自动重连；投送方式是全局设置。二维码链接本身即配对凭证，请勿公开分享。
- AI 仅使用视觉模型；模型的视觉能力由名称/能力字段启发式判断，可能不准确，需要手动确认。生成会调用第三方 API 并产生费用。
- AI 识图 World ID 依赖照片上印字的清晰度；反光、裁切、模糊会导致失败或误识别，关联后请复核。批量识别会逐张调用视觉模型，耗时与费用随照片数量增加。
- 银河黑洞是实验性背景，默认隐藏；需在管理台开启「实验性背景」后才可使用。它依赖 WebGL，低端 GPU 上可能占用较高；关闭开关会自动回退到星轨。
- 网站同步需要你自己的后端接口；云盘 API 需要自行申请 Google / 百度开放平台应用。
- 示例插画与内置世界为虚构起始内容，不是真实 VRChat 截图或实时数据，可在管理台清理。
- VRChat 世界查询需要自行部署认证代理；本项目不包含该代理或任何凭据。
- 非官方 VRChat 同人作品，与 VRChat Inc. 无关联。
